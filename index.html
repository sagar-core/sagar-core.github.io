Project Lead · Math & Algorithms

ATM Cash Combination Optimizer

Problem: ATMs must determine valid banknote distributions for exact cash withdrawals while adhering to hardware cassette limits and minimizing total dispensed notes.

Solution: Formulated currency dispensing using Linear Diophantine Equations (a₁x₁ + a₂x₂ + … = N). Implemented GCD/Bézout solvability tests to verify feasible payouts and computed all non-negative integer note combinations to select the optimal payout.

  • Linear Diophantine mathematical model
  • Extended Euclidean & GCD solvability checks
  • Combinatorial non-negative note allocation
  • Denomination constraint & edge case handling
